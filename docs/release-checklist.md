# Release Checklist

This checklist is for public source releases.

## Scope

- Release type: no-hardware chat-client alpha.
- Current version: `0.1.0-alpha.7`.
- Product topology: `chattybara` is the TUI/CLI chat client; `orca-*` crates
  are consumed from `https://gitlab.com/yokij/orca`.
- Public chattybara home: `https://github.com/nvk/chattybara`.
- Hardware claim: no hardware required for default checks.
- License: MIT.

The workspace crates are marked non-publishable.

## TUI Ship Gates

- `chattybara chat tui --setup-preview` reports `product=chattybara` and `modem_engine=orca`.
- Bare `chattybara chat tui` opens guided setup with no-hardware native loopback selected.
- The TUI renders setup/radio, transcript, beacon/CQ monitor, mailbox, file offers, composer, status, and context-help surfaces.
- The station mode registry reports chat, JS8Call, WSJT-X/FT8, fldigi, CW, and
  PSK Reporter scaffolds with capability flags.
- Station fake-event logs can be replayed without external apps.
- Transmit/reporting guards reject unarmed actions.
- Safety text such as `DRY RUN` is visible without relying on color.
- Mail and file offers are selectable with keyboard navigation.
- No TUI test requires radio hardware, virtual audio cables, private traffic,
  hosted CI, or live serial/audio access.

## Release Notes

Before tagging:

- Update `CHANGELOG.md`.
- Confirm `README.md` describes chattybara as the chat client and orca as the modem engine.
- Confirm `CONTRIBUTING.md` and `docs/provenance/README.md` still prohibit tainted implementation details.
- Confirm `SECURITY.md` has the current reporting path.
- Confirm local preflight passes. Do not depend on hosted pipelines for local release prep.

## Tag

```sh
git tag -a v0.1.0-alpha.7 -m "chattybara 0.1.0-alpha.7"
git push origin master --tags
```

## Public Release

Create a public release from the tag with:

- A short summary copied from `CHANGELOG.md`.
- Source archive links generated by the forge.
- Optional binary archives after local smoke tests pass.
